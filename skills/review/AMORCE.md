# Review d'une pull request

Avant toute relecture de pull request — self-review ou auto-review avant de
soumettre la sienne, traitement d'une review reçue, review de la PR d'un
collègue, vérification de ses corrections —, charge le skill `slash:review`.

Il prend la place de `slash-review-code` et `slash-pr-review` du dépôt
slash-interim, dont les descriptions matchent les mêmes phrases. Ne pas les
charger sur ces quatre situations : le premier audite la conformité aux
guidelines au lieu de ce que le ticket demandait, le second poste les réponses
et résout les threads sans arbitrage.
