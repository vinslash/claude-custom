# Rédaction destinée à un relecteur humain

Avant de rédiger une description de pull request, un commentaire de code review
ou un message de commit, charge le skill `slash:redaction` — et charge-le **avant**
d'écrire le texte, pas après l'avoir écrit.

Même chose avant de rendre un **livrable écrit long** qu'un humain va relire :
document de plan, plan soumis par `ExitPlanMode`, handoff, analyse, dossier de
décision. La passe d'élagage qu'impose ce skill se fait avant de rendre, pas
après s'être fait retoquer.
